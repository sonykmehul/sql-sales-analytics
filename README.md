# SQL Sales & Customer Analytics

This project focuses on analyzing transactional sales data using PostgreSQL.
It demonstrates SQL analytics techniques to derive insights related to
revenue trends, customer behavior, and product performance.

## Dataset Overview
- Synthetic but realistic sales dataset
- ~130k records across 7 tables
- Tables include customers, orders, order_items, products, categories, payments, and returns

## Key SQL Concepts Used
- Multi-table joins
- Aggregations
- Common Table Expressions (CTEs)
- Window functions
- Time-series analysis
- Query optimization basics

## Project Structure
- schema/ : Database schema (CREATE TABLE statements)
- data/ : Data generation scripts
- queries/ : Daily SQL analytics queries
- notes/ : Insights and observations (optional)

## Goal
The goal of this project is to practice and demonstrate real-world SQL
analytics skills that are commonly used in backend and data engineering roles.
